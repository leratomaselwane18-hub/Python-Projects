# Python-Projects
BMI Calculator built in Python 
A beginner-friendly Body Mass Index (BMI) calculator built in Python and Jupyter Notebook as part of my data analytics learning journey.

## Project Overview
This script takes user input for name, weight (in pounds), and height (in inches), calculates the user's BMI score, and outputs a personalized health classification message.

## Python Concepts Used
- **User Input & Type Casting:** Using `input()` and `int()` to collect and convert numeric values.
- **Arithmetic Operators:** Applying the standard BMI formula `(weight * 703) / (height * height)`.
- **Conditional Logic:** Using nested `if`, `elif`, and `else` statements to categorize BMI ranges and validate inputs.

## How to Run
1. Download `BMI Calculator.ipynb` from this repository.
2. Open the file in **Jupyter Notebook** or **JupyterLab**.
3. Run each cell in order and enter your name, weight, and height when prompted.
